SolarWinds Compliance Invariants

All 1,572 hybrid server and network nodes are ingested from SolarWinds Orion SWIS on a 600-second cadence. Health tiers are classified authoritatively according to strict SLA thresholds:

  • High Health (1,396 Nodes): Operational Status UP, CPU Load < 75%, and Memory Used < 80%.
  • Medium Health (89 Nodes): Operational Status WARNING, or CPU Load / Memory Used between 75% and 90%.
  • Low / Critical Health (87 Nodes): Operational Status DOWN, CRITICAL, or CPU Load / Memory Used > 90%.
